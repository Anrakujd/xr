# WebXR Immersive Learning

![License: CC BY 4.0](https://shields.io)

An immersive educational platform developed as part of the **ICT Education Study Program (Pendidikan TIK)** at the **Faculty of Teacher Training and Education (FKIP)**, **Universitas Parahyangan (UNPAR)**.

This project leverages the power of WebXR to provide an accessible, browser-based immersive learning experience that supports both Augmented Reality (AR) and Virtual Reality (VR) environments.

## 🌟 Features
- **Cross-Platform Support:** Compatible with VR Headsets (Meta Quest, HTC Vive), Mobile AR, and Desktop browsers.
- **Interactive Learning:** Designed for educational simulations and 3D visualizations.
- **Web-Based:** No installation required; runs directly via a web browser.

## 🛠️ Tech Stack
- **[A-Frame](https://aframe.io):** For building the 3D/VR/AR scenes.
- **JavaScript:** For custom logic and interactivity.
- **HTML5 & CSS3:** For the structural and visual framework.
